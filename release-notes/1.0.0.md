jOSQP 1.0.0 is a pure Java quadratic-programming solver, with a Java 8 compatible library and optional Vector API support.

- **OSQP 1.0 alignment:** updated defaults, duality-gap termination checks, settings name bridges and combined vector/matrix updates. The backend remains direct QDLDL; full native C API parity is not claimed.
- **Correctness:** fixed repeated model updates, scaling and data ownership, objective offsets/direction, parsing, polishing and infeasibility checks; added stricter input validation.
- **Faster simulations:** an index-based bulk builder avoids boxed coefficient maps; reusable factorisation workspaces and specialised short-column solves reduce allocation and solve time.
- **Build and tests:** JUnit 5, CI on Java 8/17/21 and optional Vector tests on Java 26, signed Maven Central artifacts with sources, Javadoc and license notices.
- **Benchmarks:** a broad, independently validated comparison against native OSQP is documented in [BENCHMARKS.md](https://github.com/quantego/josqp/blob/master/BENCHMARKS.md).

**Migration:** off-diagonal quadratic coefficients now mean `a * x * y`, as documented, rather than `2 * a * x * y`. Code using the previous halving workaround must pass the full coefficient. Diagonal terms are unchanged. Defaults, input ownership and validation also changed; see the [full changelog](https://github.com/quantego/josqp/blob/v1.0.0/CHANGELOG.md#100---2026-10-08).
